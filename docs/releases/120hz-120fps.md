### Bug (persisting): 120Hz Game Mode toggle resets / 120 FPS not staying enabled

- Device: Game Helio G100
- Android: Android 16 / API 36
- Screen / feature: "120 FPS frame-rate" — setting labeled "Enable 120Hz Game Mode (gameplay only)"

Steps to reproduce
1. Open Settings → Game Helio G100 → "120 FPS frame-rate".
2. Turn ON "Enable 120Hz Game Mode (gameplay only)".
3. Launch a supported game or otherwise trigger the game-mode service.
4. Background the game (press Home or open another app), or exit the game.
5. Return to the Game Helio G100 setting.

Observed behavior
- The toggle can be turned on but is later found turned OFF after the app/service/background/exit sequence. 120fps is not persistently enabled and features that rely on 120 Hz are not available consistently.

Expected behavior
- The user-chosen toggle state should persist across app launches and background/exit cycles (or the UI should clearly explain if the setting is only transient and will be auto-disabled). If the feature is strictly "gameplay only", the UI should indicate when it is active and whether a persistent enable is unsupported.

Info to collect
- Device build (build fingerprint / build number)
- App package and version
- Exact timestamp (UTC) when the toggle was observed flipping
- adb logcat capture around the time of the flip (filter for `GameModeController`, `HighRefreshHelper`, `ActivityManager`, `WindowManager`)

Notes / suggestions for devs
- Check the game-mode background service that monitors foreground apps and ensure it does not forcibly reset the stored preference when a monitored app exits.
- Add a clearer UX message when mode is only active for foreground gameplay (e.g., show a persistent status line: "Active while a supported game is running").
- If relevant, capture logs from when the toggle flips (service lifecycle) to see what event resets the preference.
